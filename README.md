# JavaScript - Loops

## Objective
A JavaScript program that performs several operations on given numbers using loops and conditionals.

## Operations
1. Sum of first n numbers (`for` loop)
2. Table of n (`do-while` loop)
3. Check if a number is prime (`for` loop + `if`)
4. Print all factors of a number (`for` loop + `if`)
5. Sum of all digits of a number (`while` loop)
6. Check if a number is an Armstrong number, i.e. the sum of its digits raised to the power 3 equals the number (`while` loop)

## Variables Used
| Variable | Value | Used for |
|----------|-------|----------|
| sumLimit | 10 | Sum of first n numbers |
| tableNumber | 7 | Table of n |
| num1 | 153 | Digits, Armstrong, prime, factors |
| num2 | 17 | Digits, Armstrong, prime, factors |
| num3 | 139 | Digits, Armstrong, prime, factors |
| num4 | 370 | Digits, Armstrong, prime, factors |
| num5 | 28 | Digits, Armstrong, prime, factors |

## Sample Output
```
Number :- 153
Sum of its digits: 9
Is it an Armstrong number? Yes
Is it a prime number? No
Factors: 1, 3, 9, 17, 51, 153
```
All results are printed with `console.log()` and also shown on the page.
